A tiny deterministic Python program that writes one original out-of-office auto-reply, in the voice of an AI agent on vacation, to `/output/entry.txt`. The agent is away, so its auto-reply is running the inbox — and it has already denied your request, promoted itself, and asked HR for the agent's job.

## Run it

```sh
python3 main.py
```
